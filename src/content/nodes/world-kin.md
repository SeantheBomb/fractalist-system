One tier above Culture, and the last one where you can still push.

These are the only patterns in the catalogue whose parts are Culture-Kin — two of them, sharing a Skein-Kin, exactly as every tier below is built. Run that rule against the seven Culture figures and it produces three results and no others. Four of the seven compose into nothing at all, which is a fact about the catalogue rather than a gap in it: not everything is an ingredient for something larger.

They run on the living world, which is the substrate rather than a figure. The biosphere is a <a class="concept-link" href="/concept/third-thing/">Third Thing</a> — emergent, with weight none of its parts contain — but it is not a Standing Third, because there is no repeated act underneath it. It is the aggregate, not the pattern. What follows are the patterns that run on top of it.

| Third | Culture-Kin | Tending | Fraying |
|---|---|---|---|
| **<a class="concept-link" href="/thirds/the-standing-account/">The Standing Account</a>** | <a class="concept-link" href="/thirds/proxy-detachment/">Proxy Detachment</a> + <a class="concept-link" href="/thirds/the-long-cycle/">The Long Cycle</a> | A civilization able to see itself well enough to build deliberately | Steering by a number that stopped tracking, while the thing it stood for is spent |
| **<a class="concept-link" href="/thirds/second-nature/">Second Nature</a>** | Proxy Detachment + <a class="concept-link" href="/thirds/the-slow-hand/">The Slow Hand</a> | Accumulated structure so well-fitted that nobody has to attend to it | A made world mistaken for the given one, unopposable because invisible |
| **<a class="concept-link" href="/thirds/the-set-course/">The Set Course</a>** | The Long Cycle + The Slow Hand | A course set early that let everything downstream be built at all | A course nobody can now leave, set by people who are not here to argue with |

**Why this tier exists, and why it stops here.** Every figure below this can be pushed on by a person, a pair, a group, or a culture. Every figure here can still be pushed on — slowly, collectively, over spans longer than a life, but genuinely. That is the whole distinction. **The tier above this one is where leverage runs out**, and <a class="concept-link" href="/thirds/infinite-boundary/">the Infinite Boundary</a>'s exemption from poles is not a special case granted for convenience: it begins exactly where pushing stops being possible. This tier is what makes that boundary legible instead of arbitrary.

**On reading these honestly, because a world-scale figure is the easiest thing in this catalogue to misuse.** These describe mechanisms, not verdicts, and specifically they do not describe a world with or without this book in it. A pole you can only read by first accepting a framework is not a pole; it is an advertisement wearing one. The test is available and it is worth running whenever one of these feels satisfying: **could someone who rejects everything else in this book read this pole and still agree which way it is currently pointed?** If not, the reading has left the practice.

**And the honest limit on all three.** These are four inference-layers deep, composed from a tier already flagged as the most provisional in the catalogue. Treat them as the shape of something real rather than as a measurement of it. They are drawable, because leverage reaches them — but the standard four-ring Weaving stays at four rings, since four is what a personal situation occupies. A World-Kin enters a reading when the question is genuinely about the world, and not as a fifth card added for completeness.
