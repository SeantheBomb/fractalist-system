**Proxy Detachment is worth reading against its parents, because the composition is unusually tight.** A measure *is* a return path — the channel by which what a system produced gets back to whoever sets its rules. Fuse that with a resource nobody is positioned to protect and you get the specific case where the channel can come apart from what it carries: the number keeps arriving, on time, whether or not it is still about anything. That is not a coincidence between two figures. It is the Skein-Kin's return path, one tier up, wearing a number — and like any running figure it can run stronger or weaker.

**Independent Convergence is the one figure in this catalogue whose fusion is defined by an absence, and it widens the rule for how parts meet rather than breaking it.** Two parts meet when something links them. From the Skein tier up, that link is everywhere else a shared component; here it is the same pressure, met separately, with no path between the two. Independent Convergence is two instances of the same Skein-Kin occurring with *no* shared component anywhere between them, and that missing connection is not a flaw in the derivation. It is the entire content of the figure. Two groups arriving at the same design with a path between them have copied; the same two with no path have found. The absence is what carries the evidence, which is why this is the only place in the catalogue where an absence does the joining.

*Note on this tier: it is three inference-layers deep, built by composing figures rather than observed directly. Treat it as provisional, and anything built on it as more provisional still.*
