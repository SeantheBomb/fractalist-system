Triggered by circumstance rather than calendar — which is also why nineteen of them fit a year without dividing into anything.

| Meeting | The Turning | What it builds |
|---|---|---|
| Escalation | **The Ceasefire Dinner** — after a real fight, each cooks one dish | Escalation gets a reliable off-ramp |
| <a class="concept-link" href="/thirds/the-standoff/">The Standoff</a> | **Who Goes First** — a coin flip decides who speaks first about the unsaid thing | Stalemates break by structure, not willpower |
| <a class="concept-link" href="/thirds/the-pairing/">The Pairing</a> | **Trading Places** — swap the driver and the brake for a day | Each learns the cost of the other's role |
| <a class="concept-link" href="/thirds/watering-another/">Watering Another</a> | **The Naming of Growth** — tell someone one thing you've watched grow in them | Growth gets witnessed |
| <a class="concept-link" href="/thirds/answering-for/">Answering For</a> | **The Held Tongue** — a conversation where you may only ask questions | Capacity stays with its owner |
| <a class="concept-link" href="/thirds/filling-the-gap/">Filling the Gap</a> | **The Checking** — ask directly about one assumption you've been running | Assumptions get tested before they harden |
| <a class="concept-link" href="/thirds/the-guard/">The Guard</a> | **The Unarmoring** — share one thing you'd normally armor | Protection stops preventing the connection |
| <a class="concept-link" href="/thirds/reading-the-room/">Reading the Room</a> | **The Weather Report** — each names what they think the other feels, then gets corrected | Projection separates from perception |
| <a class="concept-link" href="/thirds/connection-first/">Connection First</a> | **The Long Preamble** — a meeting whose first half is deliberately not about the thing | Content lands because connection preceded it |
| <a class="concept-link" href="/thirds/the-rising-bar/">The Rising Bar</a> | **Good Enough Day** — deliberately do something to a standard you'd normally reject | Sufficiency becomes possible again |
| <a class="concept-link" href="/thirds/the-sliding-floor/">The Sliding Floor</a> | **The Original Terms** — revisit what you both agreed to at the start | Drift becomes visible while it's still small |
| <a class="concept-link" href="/thirds/the-shared-story/">The Shared Story</a> | **The Two Tellings** — both tell one shared memory separately, then compare | Joint memory stays honest |
| <a class="concept-link" href="/thirds/the-echo/">The Echo</a> | **The Disagreement** — find one thing you genuinely disagree on, and don't resolve it | Two positions survive contact |
| Typecasting | **The Wrong Role** — each does the thing the other is "the one who does that" | Roles stay permeable |
| <a class="concept-link" href="/thirds/gaming-the-terms/">Gaming the Terms</a> | **The Spirit Reading** — reread an agreement and ask what it was actually for | Purpose outranks letter |
| <a class="concept-link" href="/thirds/the-naming-contest/">The Naming Contest</a> | **The Shared Word** — invent one word together for something only you two experience | Vocabulary becomes shared rather than contested |
| <a class="concept-link" href="/thirds/the-unbridged-gap/">The Unbridged Gap</a> | **The Teaching** — teach each other something from your own domain, to a beginner standard | Expertise stays transmissible |
| <a class="concept-link" href="/thirds/the-arrangement/">The Arrangement</a> | **The Direct Ask** — one thing asked for plainly rather than engineered | Directness stays available |
| <a class="concept-link" href="/thirds/the-tested-price/">The Tested Price</a> | **The First Price** — openly haggle over something low-stakes and silly | Testing becomes normal rather than insulting |
