**[The Keepsake](/thirds/the-keepsake/), fused with itself** — the same pattern running on both sides, meeting in two people. A figure's tier is what it's made of, not a rank it was given.

**Tending.** Each telling fills more gaps from the other's memory, so the two stories blend tighter into one..

**Fraying.** The two talk it over less, and each one's memory drifts back toward its own version..

**Its Turning.** Look. What it builds: joint memory stays honest.
