**[The Tide](/thirds/the-tide/), fused with itself** — the same pattern running on both sides, meeting in two people. A figure's tier is what it's made of, not a rank it was given.

**Tending.** Each pull meets a quicker, harder pull back, so the shared thing is held tighter near the middle and moves less..

**Fraying.** Each pull meets a weaker, slower pull back, so the shared thing drifts further toward one side before it returns..

**Its Turning.** Fray. What it builds: stalemates break by structure, not willpower.

Catalogued in [The Dyad-Kin](/node/dyad-kin/), alongside every other figure at this scale.
