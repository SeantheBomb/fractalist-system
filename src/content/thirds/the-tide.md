**The Local Rule.** Returning toward a setpoint. This is a Self-Kin figure: one person, repeating one thing. Everything further out in the catalogue is built by fusing figures like this one together.

**Tending.** Each time it is pushed away, the pull back to its usual level comes faster and holds tighter..

**Fraying.** The pull back loosens, so each push carries it further off before it returns..

**Its Turning.** Tend. What it builds: rest stops needing to be earned.
