# Extreme Cut Changelog

The v3 draft was cut hard across all three tiers from `Cut_Merge_Candidates.md`, audited by the panel for the gaps the cut opened, repaired with reworked add-backs, and rescored. Every removed paragraph is in `Cut_Ledger.md` so nothing is lost; this file explains each decision.

## Read this first

1. **Words.** v3 101,262 → after the cut 70,141 → after the add-back **71,795** (in-scope words; the full file counts 112,358 → 81,237 → 82,891, against a 93,739-word source). 340 paragraphs deleted (31,176 words), 211 paragraphs edited to carry a folded sentence or a bridge, then 66 edits and 2 inserts restored 1,666 reworked words.
2. **The cut did not raise chapter scores; it also did not lower them, once measured fairly.** Raw chapter medians fell (below 3: 18 chapters → 43 of 91). But the 14 chapters the cut never touched fell by -0.39 on average between scoring rounds too (the earlier scores were partly selected for passing), so part of the drop is measurement drift. Against that control, cut chapters moved: One Stated Aim +6 pts, Every Paragraph Earns +8, Order Builds to Arrival -1, Delivers Something Usable -7. That is small. The control has only 14 chapters, so treat these as indications. **The honest summary: the book is 26% shorter and scored about the same.** The hypothesis that deleting redundant paragraphs would raise "Every Paragraph Earns" was not borne out.
3. **A failure in the cut, caught by the audit.** The Deck's replacement name list was rejected by a size guard while its table deletions went through, leaving a "Self-Kin" label over a World-Kin table and no deck. All ten reviewers flagged it; the add-back restored a compact name list (about 230 words). Lesson for any future cut: delete only after the replacement text is accepted.
4. **Headings stay.** Merging chapters was done by folding content and leaving a short signpost under the original heading, because removing a heading would break `reconcile`, the Derivation Map and the site's node mapping. `reconcile` is clean on the final draft; no anchor phrase was lost.
5. **Add-backs are reworked, not restored.** One sentence for sentence-sized gaps, at most half the original for paragraph-sized gaps, preferring an edit to a surviving paragraph. 9 gaps were skipped because the editors judged the cut right; 6 add-back edits were rejected by guards (listed below).
6. **Still to do.** The audit's "still bloated" notes name 190 places in 52 chapters for a second, gentler cut; the panel now scores 43 chapters below 3, concentrated in chapters whose cuts left the order unbuilt (see "Chapters that dropped most").
