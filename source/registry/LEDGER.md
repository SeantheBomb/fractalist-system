# Decisions ledger: what is currently true (2026-10-01)

**L0. Order of truth (Sean, 2026-10-01).** The sources are the primary truth, and the master manuscript is the secondary truth. Everything else (staging, companions, harnesses, the Weaving builds) is an artifact and yields to those two. The one exception is anything about the Standing Thirds: it is being reworked, so it is held open until the rework settles it, and neither the manuscript nor any artifact decides it in the meantime.

Each line is a settled decision, stated by the author or established by the verified research. Anything that contradicts a line is a contradiction to report.

**L1. Poles.** Tending = the loop strengthening; Fraying = the loop weakening. Neither is good or bad (the rope: a lifeline or a snare). A vicious cycle running hard is Tending. Tending is not "the healthy expression" and Fraying is not "the flaw". (`harness/poles/GUIDE.md`)

**L2. Two-pole rule.** Every running figure has both directions; a stopped pattern has neither. The Infinite Boundary has no poles.

**L3. Composition.** Composition is recursive and has multiple valid permutations: the same figure can come from several pairs, and one pair can make several figures. A combined pattern's type and direction cannot be derived from its parts' signs alone. Which loop dominates depends on strengths (Meadows: shifting dominance; Sellers: the loop that "predominates"). Combining by type:
- reinforcing + balancing depends on dominance;
- balancing + balancing settles between the goals;
- reinforcing + reinforcing reinforces, unless the parts brake each other.

**L4. Connector rule.** When two parts run the same direction, the meeting reinforces: it strengthens if both are Tending and weakens if both are Fraying. When they run opposite directions, it is held: each checks the other, and which way it settles is open.

**L5. The Nest runs both ways.** A Global Form at one scale is a Local Rule at the next, going down as well as up. It is gated by connection.

**L6. Speed.** Weather, Climate and Terrain are reading speeds, distinct from ring position. Brush, Tree and Forest are the accumulation axis. "A disturbance moves what shares its timescale." Speed is not a property of a ring.

**L7. No exceptions.** Widen the existing rule instead of adding an exemption.

**L8. Agency (Weaving).** The person sets how each card stands and chooses where to go. Nothing else is chosen for them or by them. A Weaving describes; it never predicts an outcome or hands down a verdict. It never requires naming a cause or assigning blame. The lever must be something the person can actually wield.
